# Evaluación

## Descripción

Proyecto desarrollado como parte de la evaluación del programa ADSO.

## Tecnologías utilizadas

* Flutter
* Dart
* Git
* GitHub

## Instalación

1. Clonar el repositorio.
2. Entrar a la carpeta del proyecto.
3. Ejecutar:

```bash
flutter pub get
```

4. Ejecutar la aplicación:

```bash
flutter run
```
